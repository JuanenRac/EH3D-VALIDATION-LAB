# EH3D-VALIDATION-LAB: not yet

Good ideas that are not in the current version. Writing them here keeps anybody from implementing them early or twice.

| Idea | Why not yet | Revisit when |
|---|---|---|
| Golden files made by the real reference program on the real corpus | The folder with the originals is the owner's to name; only copies with a SHA-256 manifest are worked on, never the originals | the owner points to the folder |
| Performance targets | Sizes of reference cases are defined first; speed is measured, not promised | the first corpus run is done |
| Signing the manifest of a golden set | The checksum list already shows a change; a signature needs a key policy of the owner | the first real golden set exists |
| Telling whether copies are on different media | The operating system gives no reliable answer across platforms | a real set is verified |
| A task kind for the server | The server has no kind of task for a corpus run yet | the server accepts tasks from the engines |
