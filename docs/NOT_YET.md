# EH3D-VALIDATION-LAB: not yet

Good ideas that are not in the first version. Writing them here avoids implementing them early.

| Idea | Why not yet | Revisit when |
|---|---|---|
| Performance targets | Sizes of reference cases are defined first; speed is measured, not promised | after the first corpus run |
| Signing the manifest of a golden set | The checksum list already shows a change; a signature needs a key policy of the owner | after the first real golden set exists |
| Telling whether copies are on different media | The operating system gives no reliable answer across platforms | when a real set is verified |
